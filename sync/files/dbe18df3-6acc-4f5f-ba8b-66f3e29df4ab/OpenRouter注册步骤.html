🚀 OpenRouter 免费 Key 注册步骤

拿到 Key 后，手机上的 AI秘书 就能直接对话，不需要电脑开代理。
1打开 OpenRouter 网站
手机或电脑浏览器访问：
https://openrouter.ai
2注册账号
点右上角 Sign Up → 选 Email。
用你自己的任意邮箱（QQ 邮箱 / 163 / 126 都行，不强制 Google 或 GitHub 账号）→ 设个密码 → 注册。
免费额度够日常聊天，不需要绑信用卡。
3创建 API Key
① 登录后点右上角头像 → 点 Personal → 选 API Keys
（如果菜单里没看到，直接访问 openrouter.ai/settings/keys）
② 点 + New Key
③ 名称填「恩子工作台」
④ 点创建后复制这串字符：
sk-or-v1-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
4在工作台填入 Key
① 打开「我的工作台」
② 点底部 我的
③ AI 服务预设 切换到 OpenRouter
④ 把刚才复制的 Key 粘贴进去
⑤ 点保存
5回到 AI秘书 测试
返回首页点 AI秘书，发条消息，应该能正常回复了。
💡 小提示：工作台默认使用免费模型 deepseek/deepseek-chat:free（带 :free 后缀）。OpenRouter 免费 Key 必须选带 :free 后缀的模型才能调用；如果以后想换模型，可到 openrouter.ai/models 筛选 Free 标签。
⚠️ 注意：不要把 Key 截图发给别人。Key 只在你的手机里保存，换手机需重新填。
