🚀 DeepSeek 官方 API Key 步骤

拿到 Key 后，手机/电脑上的 AI秘书 都能直接对话，不需要本机代理。
1打开 DeepSeek 开发者平台
手机或电脑浏览器访问：
https://platform.deepseek.com
2注册账号
点 注册 → 用手机号或邮箱注册 → 验证登录。
新用户免费送 500 万 tokens，不用绑信用卡，日常对话够用很久。
3创建 API Key
① 登录后点左侧 API Keys
② 点 创建 API Key
③ 名称填「恩子工作台」
④ 点创建后复制这串字符：
sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
4在工作台填入 Key
① 打开「我的工作台」
② 点底部 我的
③ AI 服务预设 切换到 DeepSeek 官方
④ 把刚才复制的 Key 粘贴进去
⑤ 点保存
5回到 AI秘书 测试
返回首页点 AI秘书，发条消息，应该能正常回复了。
💡 小提示：工作台默认使用 DeepSeek 官方模型 deepseek-v4-flash（便宜、快、日常够用）。如果想换更强的模型，可在「我的 → 模型名」填 deepseek-v4-pro。
⚠️ 注意：不要把 Key 截图发给别人。Key 只存在你的手机里，换手机需重新填。500 万 tokens 用完后可在 DeepSeek 平台低价充值。
