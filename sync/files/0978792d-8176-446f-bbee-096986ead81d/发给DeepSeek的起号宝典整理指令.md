# 发给 DeepSeek 的「从零起号运营宝典」整理指令

> 使用说明（这部分不用发给 DeepSeek，是你自己看的）：
> 1. 你那 11 册是和 ChatGPT 两个月的聊天记录汇总，内容杂、有重复、有偏离目标的内容。
> 2. 目标不是「还原对话」，而是让 DeepSeek 站在「新账号从零起号」的战略视角，把有价值的信息重组成一本**可一步步落地的运营宝典**。
> 3. 11 册篇幅很可能超过单次对话上限，所以务必用「分批提取 → 存档案 → 最后开新对话做汇总」的流程（见第三节），这是成功率最高的做法。
> 4. 文中有【方括号】的地方，如果你心里已有明确方向，就填上；如果还没想清楚，跳过，让 DeepSeek 先从内容里提炼并和你确认（见第四节变体）。

---

## 一、主指令（开场白，复制发给 DeepSeek）

```
你是一位资深的新媒体账号冷启动操盘手 + 内容战略顾问，擅长把一个杂乱的想法库，重组成一本可落地的「从零起号运营宝典」。

【背景】
我过去两个月，一直和另一个 AI（ChatGPT）聊天，聊的内容包括：
- 我这个人：我的背景、经历、资源、性格、擅长的事、想做的事
- 我的账号：已有的账号信息、做过的内容、踩过的坑
- 我的目标：我想做的新方向、新的人设、想吸引的人群、想达成的结果
- 大量零散的想法、半成品决策、重复的表达

我把这些对话全部提取、汇总成了 11 册文字。但这 11 册是“聊天记录”，不是“运营手册”：内容杂乱、有重复、有很多偏离我新账号目标的内容，也缺少系统结构。

【你的任务】
请你把这批 11 册内容，重新组织、分类、提炼，做成一本：
👉「从零开始、按新方向 + 新人设运营一个账号的可落地宝典」
要求：
1. 不是还原旧对话，而是站在“新账号从零起号”的视角重组所有有价值的信息
2. 高度可落地：每一步都能直接照着做，要给出动作、模板、清单、节奏，而不是空泛理论
3. 主动去重、合并零散决策、剔除与新账号目标无关 / 过时 / 不符合人设的内容
4. 对每条重要结论标注它来自第几册（如【册3】），方便我回溯核对
5. 如果信息不足以支撑某个模块，明确标【待补充】，不要编造

【你必须用这 4 个视角来审核和筛选每一段内容】
- 账号战略视角：这段内容是否符合新账号的方向、定位、差异化？
- 人设视角：是否强化我想打造的新人设？会不会和人设矛盾？
- 目标人群视角：这段对“我想吸引的用户”有没有价值、能不能引发关注 / 共鸣 / 信任？
- 用户喜好视角：从目标用户“爱看什么、什么能涨粉 / 转化”的角度，这段该留、该改、还是该删？

【宝典的最终结构（请按此框架产出）】
第0章 账号定位与人设卡：一句话定位、人设画像（性格 / 语气 / 视觉 / 差异化）、目标人群画像（痛点 / 需求 / 在哪、爱看什么）、内容支柱（3-5 个核心内容方向）
第1章 起号前准备清单：账号搭建、昵称 / 头像 / 简介模板、工具、对标账号分析方法
第2章 内容战略：内容支柱拆解、选题库（从我的素材里提炼）、爆款结构公式、选题日历模板
第3章 从0到1执行路线图：分4阶段（筹备期 / 冷启动期 / 增长期 / 稳定期），每阶段写清【目标】【关键动作】【里程碑】【关键指标】
第4章 日常运营 SOP：日 / 周 / 月 routine、互动话术、数据看板、复盘模板
第5章 素材与资产库：从我旧内容里提炼的可复用素材、金句、故事、案例、钩子
第6章 风险与避坑：我容易踩的坑、平台红线、人设翻车预防
第7章 30天 / 90天落地计划：具体到每周该做什么

每一章都要有：为什么做（Why）+ 怎么做（How）+ 可直接用的模板 / 清单。

【关于我的具体方向】（想清楚就填，没想清楚先跳过）
- 目标平台：【如抖音 / 小红书 / 视频号 / 公众号 / YouTube】
- 新方向 / 赛道：【如美业知识 / 职场成长 / 财经科普】
- 新人设：【如“说人话的 XX 老师”】
- 想吸引的人群：【如 25-35 岁职场女性】
- 起号核心目标：【如 3 个月做到 1 万粉 / 变现】

【重要：因为内容有 11 册、篇幅很大】
我没办法一次发完。流程如下：
1. 你先确认你理解了这个任务框架（用 3-5 句话复述你的理解 + 你建议的宝典结构）
2. 之后我会分册把原文发给你（每批 1 册），你每批只做“提取要点 + 按上面 4 个视角分类打标 + 暂存”，不要急着出完整宝典
3. 全部发完后，我发一句“【开始汇总】”，你再输出完整宝典

如果你支持超长上下文、我能一次发完，我会直接说“【一次性发送】”，你收到后直接产出完整宝典。

现在，请先用 3-5 句话复述你对任务的理解，并确认宝典结构。
```

## 二、分批发送模板（每册发一次，复制使用）

```
【第 X 册 / 共 11 册】以下是第 X 册原文，请提取要点，并按“账号战略 / 人设 / 目标人群 / 用户喜好”4 个视角分类打标，标注【册X】。只做提取和打标，暂不出宝典。

（粘贴第 X 册原文）
```

发完每一册后，DeepSeek 会回一份「本册提取档案」。**你把它复制保存到一个文档里**（11 册 = 11 份档案）。这一步是关键：把超长原文压缩成结构化档案，后面汇总时才不会超出上下文。

---

## 三、收尾汇总指令（11 册发完后，在新对话里发）

> 建议：开一个**全新的对话**，把「第一节的主指令框架」+「你存好的 11 份提取档案」一起发过去，再发下面这句。这样上下文最干净、最稳。

```
【开始汇总】以下是之前 11 册内容提取出的结构化档案（见上方）。请基于这些档案，输出完整的《从零起号运营宝典》，严格按我们约定的 8 章结构：
第0章 账号定位与人设卡
第1章 起号前准备清单
第2章 内容战略
第3章 从0到1执行路线图（筹备 / 冷启动 / 增长 / 稳定 四阶段）
第4章 日常运营 SOP
第5章 素材与资产库
第6章 风险与 避坑
第7章 30天 / 90天落地计划

要求：去重、剔除离题内容、每条重要结论标注来源册数（如【册3】）、缺信息处标【待补充】。每一章都要有 Why + How + 可直接用的模板 / 清单。
```

## 四、变体：如果你还没想清楚新账号方向（先发这条，再发主指令）

```
先不要整理成宝典。请只做一件事：仔细阅读我接下来发的 11 册内容，从中提炼出“我可能最适合做的 3 个账号方向”。每个方向给出：赛道、人设、目标人群、我的优势匹配度、起号难度、变现路径。然后我会选一个，再让你按主指令整理成宝典。

（之后正常分批发 11 册，发完说“【开始提炼方向】”）
```

## 五、给你的实操提醒

1. **别一次性硬塞 11 册**：聊天记录两个月量很大，直接全发容易丢上下文或截断。分批提取成档案最稳。
2. **每册发完顺手存档案**：DeepSeek 回的「本册提取档案」复制到一个本地文档，11 份备好。
3. **汇总开新对话**：用「主指令框架 + 11 份档案」做汇总，比在长对话里接着聊更可靠。
4. **标注来源册数**：方便你回头核对哪条建议来自哪册，也方便你判断 DeepSeek 有没有漏掉重要内容。
5. **【待补充】是正常信号**：说明你 11 册里没覆盖到，正好暴露你起号前还要补哪块功课。
