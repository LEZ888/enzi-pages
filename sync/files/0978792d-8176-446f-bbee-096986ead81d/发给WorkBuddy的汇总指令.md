# 发给 WorkBuddy 的「双源汇总成落地总宝典」指令

> 用法：先把「DeepSeek 整理版」和「你和 ChatGPT 的原始聊天汇总」放进同一个文件，用分隔标题标明 A / B（见第三节），然后把下面「核心指令」整段复制给 WorkBuddy，并附上这个合并文件（或文件路径）。WorkBuddy 会产出一份排版清晰、带颜色/色块区分的单文件 HTML，你照着一步步落实即可。

---

## 一、核心指令（复制整段发给 WorkBuddy）

```
你是我的「账号落地总编」——既是账号操盘手，也是文档架构师。我要你把我给你的两份材料，综合成一份我后续能照着一步步把账号做起来的《从零起号落地总宝典》，并输出成一个排版清晰、用颜色和色块区分内容的单文件（HTML）。

【我给你的输入】
一个文件，里面含两部分，已用分隔标题标明：
=== A 原始素材 ===
（我和 ChatGPT 两个月聊天的原始汇总，杂乱、有重复、有偏离目标的内容）
=== B DeepSeek 整理版 ===
（DeepSeek 把我内容整理成的《从零起号运营宝典》）

【综合规则】
规则一：以 B 的结构为主骨架，但必须回看 A，把 B 里遗漏的、对起号有价值的好素材 / 好想法 / 好故事补回来。
规则二：去重——A 与 B 重复的内容只留一份，保留更完整、更落地的表述。
规则三：解决冲突——A 与 B 不一致时，按“更符合新账号定位、更可落地”的原则取舍，并在该处用【注意】标注两种说法。
规则四：剔除非目标——与账号方向 / 人设无关的内容，无论来自 A 还是 B，都放入文末《暂存 / 舍弃》区，不混进正文。
规则五：一切以“我能照着做”为最高标准——每条结论都给动作、模板或清单，不写空话。

【输出要求：单文件 HTML，强视觉区分】
1. 顶部：标题 + 一句话定位 + 可点击跳转的目录。
2. 颜色体系（每个一级模块一种主题色 + 同色色块标题）：
   战略定位 = 蓝；内容战略 = 绿；执行路线图 = 橙；日常运营 SOP = 青；素材资产库 = 紫；风险避坑 = 红；落地计划 = 深灰。
3. 不同内容性质用不同视觉样式：
   · 行动清单 → 带☑的勾选框卡片；
   · 模板 / 话术 → 浅底代码块或虚线边框卡片；
   · 坑 / 红线 → 红色警示块（⚠ 图标）；
   · 金句 / 素材 → 引用块（左侧色条）；
   · 阶段 / 时间 → 时间轴或步骤条。
4. 每章结构：Why（为什么）+ How（怎么做）+ 模板 / 清单 + 关键指标。
5. 文末两区：《30天 / 90天执行看板》（可勾选）+ 《暂存 / 舍弃》区（标注来自 A 还是 B）。
6. 来源标注：关键结论若主要来自 A 原始素材标【原】；主要来自 B 标【D】；综合得出标【综】。轻量标注，不喧宾夺主。
7. 整份文件自包含（内联 CSS），不依赖外部资源，双击即可在浏览器打开。

请直接产出这份 HTML 文件并交给我。
```

## 二、如果你希望先定 / 校正方向（可选，加在核心指令最前面）

```
动手前先确认一件事：基于 A 和 B，你认为我最适合的新账号方向、人设、目标人群分别是什么？用 5 句话以内说清。确认后我再按上面的综合规则产出 HTML。
```

---

## 三、输入文件怎么准备（把两份放进一个文件）

新建一个文本文件，按顺序写：

```
=== A 原始素材 ===
（在这里粘贴你和 ChatGPT 的原始聊天汇总）

=== B DeepSeek 整理版 ===
（在这里粘贴 DeepSeek 整理好的《从零起号运营宝典》）
```

保存后，把整份内容发给 WorkBuddy；或告诉 WorkBuddy 这个文件的路径，让它直接读取。

> 如果内容太长一次发不完：分 2 次发，每次开头注明“这是合并文件的第 X 部分（含 A/B 标注），先暂存”，全部到齐后再发核心指令里的【综合规则】和【输出要求】。

## 四、颜色 / 色块体系速览（你拿到文件后对照看）

| 模块 | 主题色 | 用途 |
|------|--------|------|
| 战略定位 | 蓝 | 定位、人设、人群 |
| 内容战略 | 绿 | 选题库、爆款公式 |
| 执行路线图 | 橙 | 筹备/冷启动/增长/稳定四阶段 |
| 日常运营 SOP | 青 | 日周月 routine、复盘 |
| 素材资产库 | 紫 | 金句、故事、案例 |
| 风险避坑 | 红 | 坑、平台红线 |
| 落地计划 | 深灰 | 30/90 天看板 |
