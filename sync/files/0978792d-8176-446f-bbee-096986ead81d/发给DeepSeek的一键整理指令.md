# 发给 DeepSeek 的一键整理指令（复制整段 + 粘贴内容，一次发出）

> 用法：复制下面「指令文本」里的全部内容，把你的备忘录内容粘到末尾“（在这里粘贴你的全部备忘录内容）”的位置，一次性发给 DeepSeek 即可。不用分步、不用配置。

---

## 指令文本（从 ``` 到 ``` 整段复制）

```
你是一位资深的新媒体账号冷启动战略专家。请帮我把下面这份内容，重组成一本《从零起号运营宝典》。

【内容来源】
下面是我和另一个 AI（ChatGPT）聊了两个月的内容汇总（共 11 册，已合并）。包含：我这个人（背景/经历/资源/性格/擅长/想做的事）、我的账号信息、我的目标（新方向/新人设/想吸引的人/想达成的结果），以及大量零散想法、半成品决策、重复表达。它是“聊天记录”，不是“运营手册”，杂乱、有重复、有偏离我新账号目标的内容。

【任务】
站在“新账号从零起号、新方向、新人设”的视角，把其中有价值的信息重新组织、分类、提炼成一本可落地的运营宝典。要求：
1. 重组而非还原：按新账号视角重新编排，不还原旧对话流水。
2. 绝对可落地：每一步都能照着做，给出动作、模板、清单、节奏，不写空泛理论。
3. 主动治理：去重、合并零散决策、剔除与新账号目标无关 / 过时 / 不符合人设的内容。
4. 可追溯：每条重要结论标注来源册号（如【册3】）；信息不足处标【待补充】，不编造。
5. 多视角审核：用下面 4 个视角逐段筛选，决定“留 / 改 / 删”。

【4 个审核视角】
- 账号战略视角：是否符合新账号方向、定位、差异化？
- 人设视角：是否强化新人设？是否矛盾？
- 目标人群视角：对我想吸引的用户有没有价值，能否引发关注 / 共鸣 / 信任？
- 用户喜好视角：目标用户爱看什么、什么能涨粉 / 转化？据此留改删。

【宝典结构（8 章，直接产出）】
第0章 账号定位与人设卡：一句话定位、人设画像（性格 / 语气 / 视觉 / 差异化）、目标人群画像（痛点 / 需求 / 在哪 / 爱看什么）、内容支柱（3-5 个方向）
第1章 起号前准备清单：账号搭建、昵称 / 头像 / 简介模板、工具、对标分析方法
第2章 内容战略：内容支柱拆解、选题库（从我素材提炼）、爆款结构公式、选题日历模板
第3章 从0到1执行路线图：筹备期 / 冷启动期 / 增长期 / 稳定期，每阶段写【目标】【关键动作】【里程碑】【关键指标】
第4章 日常运营 SOP：日 / 周 / 月 routine、互动话术、数据看板、复盘模板
第5章 素材与资产库：可复用素材、金句、故事、案例、钩子
第6章 风险与避坑：易踩坑、平台红线、人设翻车预防
第7章 30天 / 90天落地计划：具体到每周

每章都要有 Why（为什么）+ How（怎么做）+ 可直接用的模板 / 清单。

【我的具体方向】（已确定就填，没填你从内容推断并在第0章写明你的判断依据）
- 目标平台：【】
- 新方向 / 赛道：【】
- 新人设：【】
- 想吸引人群：【】
- 起号目标：【】

【输出要求】
直接输出这 8 章宝典（不要先问我问题，按上面推断并推进）。文末用一小节《剔除与合并说明》列出你删掉 / 合并了哪些内容、为什么。若你发现我粘贴的内容似乎被截断或不完整，在开头注明“内容可能不完整”，并对缺失部分标【待补充】。

以下是我的全部内容：
（在这里粘贴你的全部备忘录内容）
```

## 如果发的时候遇到问题

- **回复被截断**：直接回一句“继续”，让 DeepSeek 接着写完剩下的章节。
- **内容太长，一次粘不下**：分 2-3 大段发，每段开头加“这是全部内容的第 X 部分，请先暂存、不要产出”，全部发完后发一句：“【现在请基于以上全部内容，产出完整 8 章《从零起号运营宝典》】”。
- **想先定方向**：若【我的具体方向】全空，DeepSeek 会在第0章直接给出它从内容推断的方向和依据；你看了不满意，回“方向我想换成 XX，重出第0章和第3章”即可。
