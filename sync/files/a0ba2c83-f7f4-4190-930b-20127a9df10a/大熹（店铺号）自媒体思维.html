一、账号战略定位（主题思路层）

1.1 核心定位

一个用吉卜力画风讲护肤故事的美容院老板娘。

🟦 主题思路（我们是谁 / 为什么这样定位）
这不是美容院官方号，而是一个「有人格、有审美、有技术」的专业 IP 号。用户关注的不是一家店，而是一个活生生的人——在开平开「熹美学」小店、用漫画讲皮肤问题、分享店铺温暖的老板娘。把「店铺」变成「人」，是把一次性到店变成长期关注的底层逻辑。
🟩 具体操作思路（怎么落地成人格 IP）
① 昵称带地域 + 品类（如「开平熹美学恩子」）；② 头像用吉卜力画风老板娘立绘；③ 简介第一句说人话（「我是恩子，在开平开了家爱画画的美容小店」）；④ 所有视频以「老板娘视角」第一人称讲述，不出现「本店欢迎您」式官腔。
💡 双视角校验
消费者要的是「一个我愿意关注的人」，操盘手要的是「可识别、可分发、可转化的人设资产」。吉卜力画风同时满足：降低拍摄门槛（动画替代真人出镜尴尬）+ 建立差异化记忆点（同城唯一）。

1.3 目标用户画像（双视角交叉）

🟦 消费者视角：她们是谁、在怕什么
25–45 岁女性，开平及周边同城。深层清洁 / 敏感修复 / 抗衰需求。她们怕「被坑、被推销、做完红肿」，渴望「被理解、被专业对待」。轻熟龄敏感肌（25–40）尤其关注 抗老维稳 复合功效、对过度营销警惕、只信「良心博主」的真实信息。
🟩 操盘手视角：怎么把她们圈进流量池
用 POI 锁定 3–5 公里同城；用「痛点场景」做内容钩子拉新；用「专业科普 + 真实故事」建立信任促成团购。数据显示美容类内容在 周四 / 周五 发布转化率最高（用户周末消费决策期），务必卡点。

1.4 差异化优势

  • 内容形式降维打击：同城美容号都真人拍项目，你用吉卜力画风讲故事，独一无二
  • 项目壁垒可视化：爱马仕清洁「温和但强大」、神仙草面膜「独家草药」，动画化后同行无法复制
  • 人设真实度：广普口音、爽朗性格、真实经历，是最大的信任加分项（真实人设转化率高 2.3 倍）

二、内容栏目体系（主题思路）

三大栏目按「引流 → 信任 → 人格」递进，比例 4 : 4 : 2。

栏目占比功能内容风格目标
皮肤情绪日记40%痛点共鸣·拉新绘本演绎皮肤问题尴尬瞬间情绪扎心·结尾温暖刷到的人觉得「这画的不就是我吗」
老板娘护肤画本40%专业科普·建信任·推项目微观视角可视化项目原理生动有趣·清晰易懂觉得「这家店专业，和其他地方不一样」

💡 双视角排期逻辑
消费者视角——先被情绪击中（日记），再被专业说服（画本），最后被人情留住（故事），符合「共鸣 → 信任 → 行动」的决策链路。操盘手视角——按此比例，前两条必是引流型（挂团购），故事类不挂团购纯做信任资产，避免「每条都卖货」导致完播率下滑。
