# 恩子聊美业 · 第1条草稿（恩子拆抖音）

**选题**：30条没过500播放，问题就3个
**所属系列**：恩子拆抖音（思路开窍 / B 主力获客）
**目标人群**：自己店想做抖音、发几十条没动静、开始怀疑"我是不是不适合做抖音"的老板
**核心落点**：客户刷抖音是来找自己的，不是看你店多好；站错视角怎么拍都白搭
**结尾钩子（第1条·轻互动版）**：引评论区 + 下条预告，**不引成交**

---

## 一、口播脚本（分镜）

**【0-3秒｜钩子·停驻】**
- 画面：手机录屏一个美业账号主页（用你自己早期试错的号，或打码数据），手指圈住"作品 32 条 · 最高播放 480"。
- 台词："你这家店，发了 32 条抖音，最高一条 480 播放——是不是跟你一模一样？发了几十条，没一条破 500，你都开始怀疑：我是不是根本不适合做抖音？"

**【3-10秒｜共情·我也是】**
- 画面：恩子真人口播，表情真诚，不端着。
- 台词："我太懂这种感觉了。我当年自己开店想做抖音，也是这么过来的——发一条删一条，对着镜头卡壳，觉得自个儿嘴笨、不会拍、天生不是这块料。"

**【10-20秒｜转折·点破】**
- 画面：切脑图/黑板贴图，大字「不是你不行，是站错位置了」。
- 台词："但后来我拆了上百个美业号才反应过来：真不是你能力问题。是你从第一天起，就站错了位置。"

**【20-35秒｜核心结论】**
- 画面：左右分屏对比贴图。左「你拍的：我店多干净 / 手法多牛」打叉；右「客户想的：我这张脸怎么办 / 我这种店怎么救」打勾。
- 台词："客户刷抖音，是来找'她自己'的。她想看的是'我这种烂脸怎么救''我这种小店怎么活'，不是来参观你店有多干净、你手法多专业。你越拼命讲'我店多好'，她越划走——因为你通篇都在说你，没一句说到她。"

**【35-45秒｜抛3个问题·留钩子】**
- 画面：贴图列「问题就 3 个」，只亮第 1 个，2/3 打问号。
- 台词："问题其实就 3 个。第一，你拍的是'我想让你看什么'，不是'客户想看什么'。第二、第三是啥，这条先不展开——下条我一条条给你拆。"

**【45-50秒｜结尾钩子·轻互动】**
- 画面：恩子口播，底部字幕条「评论区告诉我」。
- 台词："你发了多少条？最高多少播放？评论区告诉我。关注恩子，美业老板的抖音思路，我带你一条条捋明白。下条见。"

## 二、视觉 / 贴图标注（专业感，不用表情包）

- 录屏主页：圈「32 条 / 480 播放」用红圈 + 放大，制造"这说的不就是我吗"。
- 分屏对比：左叉右勾，关键词大字（**客户视角** vs **店主视角**）。
- 脑图贴图：「站错位置」做主标题，下面小字「视角错了 = 白拍」。
- 结尾字幕条：评论区提问模板，降低互动门槛。

---

## 三、你融合时要注意（红线 / 节奏）

1. **录屏用你自己早期试错的号，或打码数据**——绝不明晃晃点名真实同行（防举报、限流、商务纠纷）。
2. **结尾不引成交**（别喊"找我出方案"）——第 1 条只捞关注和评论，第 10 条后再引方案。
3. **不出现"单亲 / 带娃"等隐私信息**——本条是开店经历，天然不涉及，但融思路时别顺手带出。
4. **前 3 秒必须有具体数字 + 痛点**（32 条 / 480 播放）——这是让人停下来的关键。
5. **贴图走"数据标注 + 箭头 + 大字"**，别用表情包，立得住专家感（胡楚靓式真实口播 + 专业贴图）。
6. **"我也试错过"这句必须留**——它是你和观众"同一阵线"的信任锚，删了就变"站着说话不腰疼"。

## 四、后续衔接（给你自己留的底）

- 第 2 条：把"问题 3 个"拆开讲——第 2 条讲「客户视角到底怎么站」（呼应本条第 1 个问题）。
- 每条埋的轻钩子都指向下一条，形成"追剧感"，让人关注了就不取关。
